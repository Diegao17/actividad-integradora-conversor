# Actividad Integradora - Conversor de Unidades

## Archivos
- `converter.py`: programa principal.
- `test_converter.py`: pruebas automatizadas con pytest.
- `evidencia_pytest.txt`: evidencia de la ejecución de las pruebas.

## Ejecución
1. Instalar pytest:
   `pip install pytest`
2. Ejecutar las pruebas:
   `pytest -v`
3. Ejecutar el programa:
   `python converter.py`

La tasa fija utilizada para la conversión de pesos mexicanos a dólares es de 18.50 MXN por USD.
